# Acta-pro
Agente inteligente para la gestión profesional de actas de reuniones escolares

Transformamos las reuniones entre docentes y representantes en actas profesionales, evidencias institucionales y documentos verificables en tiempo real.


# Descripción del proyecto

ACTA PRO es una plataforma basada en inteligencia artificial diseñada para automatizar la documentación de las reuniones escolares.

La solución integra la comunicación institucional, la programación de reuniones, la transcripción en tiempo real, la identificación de participantes, la generación automática de actas, la firma digital, la organización documental y el envío automatizado de evidencias.

El objetivo principal es reducir la carga administrativa del docente y fortalecer la trazabilidad documental dentro de las instituciones educativas.


# El problema

Después de una reunión con un representante, el docente debe:

* Tomar notas.
* Recordar acuerdos.
* Redactar el acta.
* Organizar la documentación.
* Archivar la información.
* Compartir una copia con el representante.

Este proceso consume tiempo y puede provocar:

* Omisión de información.
* Redacciones subjetivas.
* Pérdida de evidencias.
* Dificultades para el seguimiento.
* Documentación dispersa.

# Flujo del usuario

1. Programar la reunión

El docente y el representante acuerdan una fecha mediante Runachay.


2. Registrar la reunión

La reunión se registra en Google Calendar.


3. Sincronizar la información

ACTA PRO extrae los datos del estudiante y del representante.


4. Configurar los participantes

El docente selecciona quién asistirá a la reunión.


5. Iniciar la reunión

El sistema comienza la transcripción.


6. Analizar la conversación

La inteligencia artificial identifica acuerdos, compromisos y evidencias.


7. Generar el acta

El sistema organiza la información automáticamente.


8. Firmar el documento

El docente y el representante validan el acta.

9. Almacenar la información

El acta se clasifica en el repositorio documental.


10. Compartir el documento

El sistema envía automáticamente una copia al representante.
