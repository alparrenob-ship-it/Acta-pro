# ACTA PRO — MVP v6.8

**De una reunión a una evidencia institucional, en tiempo real.**

Versión v6.8: experiencia simplificada, micrófono real cuando el navegador lo permite y generación de acta institucional con revisión humana.

Flujo principal: Planificar → Sincronizar → Preparar → Reunión en vivo → Generar acta → Firmar → Almacenar y enviar.

Principio central: **La IA redacta y propone. El docente verifica, edita y decide.**

GitHub Pages se despliega desde `main` / raíz.
